Understanding the methods

Traditional encryption

Classical methods such as Atbash and substitution transform letters according to a simple rule. They are useful for learning the history and basic principles of cryptography, but are vulnerable to frequency analysis and brute force.

Modern encryption

AES is symmetric: the same secret key encrypts and decrypts. RSA is asymmetric: a public key encrypts and the matching private key decrypts. This project uses authenticated AES-GCM and RSA-OAEP with SHA-256.

Why hybrid encryption?

RSA is not designed to encrypt long messages directly. Hybrid encryption uses AES-GCM for the message and RSA-OAEP to protect the randomly generated AES key.

Traditional + modern integration

The integrated mode first applies Atbash or Substitution, then encrypts the transformed text with AES-GCM. RSA-OAEP protects the AES key. Decryption reverses these steps in the opposite order. The classical layer is included to demonstrate integration, not to strengthen modern security.
